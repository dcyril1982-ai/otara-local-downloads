# Отара Local 2.3.2

Локальная программа для овцеводческого хозяйства: macOS 13+, Windows 10 x64 1809+ / Windows 11 x64 и Android 8+. Русский интерфейс, центральная база на компьютере, автономный учет. После настройки обмена Android получает задания и передает факты через GitHub или Яндекс.Диск.

## Изменения 2.3.2

- Исправлен контроль качества массы в обзоре, реестре, карточках, графиках и выборе исходных измерений для первички и назначений. Отклоненные и спорные значения остаются в истории с объяснением, но не используются как текущий вес.
- В миграции СЕЛЭКС добавлены отдельные XLSX, XLS (BIFF8) и DBF без memo: выбор листа и строки заголовков, явные кодировка и единицы, сохранение оригинального файла и повторная проверка перед записью. Закрытые архивы ПЛИНОР не объявляются совместимыми. Формулы, макросы, неоднозначные значения и поврежденные архивы отклоняются.
- Для новых редакций справочников обязательны сведения об источнике, версии, публикации, владельце и условиях использования. Неизвестные сведения сохраняются явно в черновике; устаревание и отзыв имеют отдельную историю. Прежние расчеты не переписываются.
- Бирка и имя закреплены в заголовке карточки. Android получил ролевой офлайн-самоучитель с поиском и контроль качества истории массы; справочники и черновики работают без интернета.
- Обновлены встроенное обучение и руководство 2.3.2, уточнены границы совместимости и порядок сохранения данных.

## Обновление и сохранность

Устанавливайте поверх предыдущего приложения под той же учетной записью ОС. Сохраняются стадо, пользователи, настройки, папки данных и системные хранилища ключей. Android обновляйте без удаления приложения и очистки его данных; используется постоянный сертификат выпусков.

Перед первой записью с требованием читателя 2.3.2 создается аварийная копия `before-v2.3.2-…`. Ошибка ее создания отменяет запись. База после перехода требует 2.3.2; версия 2.3.1 блокирует ее открытие и изменение. Для возврата к старой программе нужна совместимая копия до обновления; последующие факты в нее не входят. Копия базы сама по себе не переносит системное хранилище ключей на другой компьютер.
