## Обновления с сохранением данных — 0.4.2

Установка поверх прежней версии сохраняет стадо, пользователей, историю, настройки и секреты. Неполные хранилища ключей и TLS не заменяются автоматически новыми подключениями. Установщик Windows защищает каталог данных; форма сервиса читает сохраненные параметры перед редактированием. Android сохраняет очередь событий, токены и активированный профиль весов.

Обновляйте на том же устройстве, под прежней учетной записью ОС и с прежним каталогом данных. Не удаляйте Android-приложение и не очищайте его данные. macOS может запросить доступ обновленной сборки к прежним ключам. Резервная копия базы не переносит системное хранилище секретов на другой компьютер.

## Возможности

- Раздел «Саппорт», отдельный сервис на центральном компьютере и персональное подключение телефонов. OpenAI GPT-6 Astra / max; резервный Kimi K3.1 Pro / max при недоступности OpenAI, включая доступ, баланс и лимиты.
- «Версии ПО»: проверка совместимости, резервная копия базы, проверка размера и SHA-256 установщика перед ручной установкой.
- Android: профили весов Bluetooth SPP / BLE и USB CDC-ACM, обязательное контрольное взвешивание, локальное распознавание номера бирки с подтверждением оператором.
- Подключение Яндекс.Диска через OAuth после согласия владельца Диска.

## Перед использованием

Сохраните резервную копию базы. Это сборки для пилотной эксплуатации: Windows без коммерческого Authenticode, macOS без Apple notarization. Конкретную модель весов необходимо проверить на оборудовании.

При переходе с Android 0.2/0.3 подпись отличается. До переустановки выгрузите очередь событий, дождитесь подтверждения в центральной базе и сохраните файл подключения. Версия 0.4 начинает постоянную цепочку подписи.

Локальный учет работает без API-ключей и GitHub. Для онлайн-поддержки нужны ключи в настройках центрального компьютера и интернет. Сервис работает, пока открыто центральное приложение; вне локальной сети телефонам нужен VPN. Секреты хранятся в Keychain / DPAPI, в установщики не включены. Контекст поддержки — документация и код версии программы; доступа к личной переписке ChatGPT у сервиса нет.

Для Яндекс.Диска требуется зарегистрированный OAuth redirect URI и вход владельца аккаунта. Автоматическая подготовка исправлений и выпуск требуют отдельных настроек GitHub Actions secrets. Изменения проходят проверку перед публикацией; лечение и кормление не меняются автоматически.

Исходники находятся в отдельном приватном репозитории. Автоматические ссылки GitHub «Source code» на странице этого репозитория содержат его служебные файлы, а не исходники приложения.
