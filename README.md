# Отара Local 2.3.5

Локальная программа для овцеводческого хозяйства: macOS 13+, Windows 10 x64 1809+ / Windows 11 x64 и Android 8+. Русский интерфейс, центральная база на компьютере, автономный учёт. После настройки обмена Android получает задания и передаёт факты через GitHub или Яндекс.Диск.

## Изменения 2.3.5

- Компьютер автоматически выдаёт задания по утверждённым регулярным планам кормления, планам взвешивания и разрешённой ветеринаром автовыдаче программы. Сроки, исполнитель и горизонт выдачи сохраняются в плане.
- Проверка выполняется при запуске программы, входе сотрудника, сохранении изменений, подготовке пакета Android и смене дня. Повторная проверка не создаёт дубликаты или пустые ревизии базы; препятствие одного плана показывается отдельно.
- В разделе «Задания» выделены сегодняшние, просроченные и будущие назначения. У задания видны исходный план и дата. Отключение плана прекращает новые выдачи; уже выданные задания отменяются отдельно с причиной.
- Для лекарственной автовыдачи нужны утверждённый протокол, явное разрешение ветеринара, ограниченный период, фиксированные животные и назначенные партии препаратов. Справочник и поиск симптомов сами не создают курсы лечения.
- Android показывает подготовленный горизонт, связь с планом и разделы «Просрочено», «Сегодня», «Ближайшие дни». Будущие действия становятся доступны в свой день. Телефон сохраняет факты без сети и ждёт подписанного подтверждения компьютера.
- Изменение плана не стирает выполненную работу, приготовленную смесь или неподтверждённую очередь телефона. Устаревшие назначения и конфликтующие события остаются для разбора специалистом.

Компьютер должен быть включён, а приложение или его настроенная фоновая задача — работать. Перед работой без связи передайте Android достаточный горизонт. При выключенном компьютере телефон не рассчитывает следующие назначения. Автовыдача не подтверждает выполнение, не списывает запасы и не создаёт бухгалтерские проведения.

## Обновление и сохранность

Устанавливайте поверх предыдущего приложения под той же учётной записью ОС. Обновление само по себе не создаёт новое хозяйство и не очищает данные: стадо, пользователи, настройки, папки данных и системные хранилища ключей сохраняются. Android 20305 обновляется поверх 20304 без удаления приложения и очистки данных; используется постоянный сертификат выпусков.

Перед первой записью регулярного плана кормления или настройки ветеринарной автовыдачи создаётся проверяемая копия `before-v2.3.5`; требование читателя повышается до 2.3.5. Ошибка резервирования отменяет запись. Такую базу нельзя открывать версией 2.3.4. Простое открытие хозяйства и выдача по прежним планам взвешивания не повышают это требование. Прежние границы 2.3.2 и 2.3.4 сохраняются; новые записи не понижают уже установленного читателя. Восстановление раннего архива — отдельная операция со сверкой последующих событий. Копия базы не переносит системное хранилище ключей на другой компьютер.
