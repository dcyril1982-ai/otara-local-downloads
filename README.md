# Отара Local 2.3.3

Локальная программа для овцеводческого хозяйства: macOS 13+, Windows 10 x64 1809+ / Windows 11 x64 и Android 8+. Русский интерфейс, центральная база на компьютере, автономный учет. После настройки обмена Android получает задания и передает факты через GitHub или Яндекс.Диск.

## Изменения 2.3.3

- В демонстрационном хозяйстве администратор может открыть «Настройки → Хозяйство → Создать рабочее хозяйство», указать название и нажать «Создать и перейти». Та же кнопка доступна в полосе демонстрационного режима.
- До перехода сохраняется полный локальный архив учебной базы. Если архивирование или запись новой базы не удались, прежнее хозяйство остается активным.
- Новое рабочее хозяйство получает отдельный идентификатор и пустой производственный учет. Учебные животные, остатки, операции и задания не переносятся. Реальные записи, случайно внесенные в демо, остаются в архиве.
- Сохраняются пользователи, логины, пароли, настройки рабочего места и учета, локальные ключи и подключение Саппорта. Прежние облачные привязки остаются источниками старых архивов. Обмен нового хозяйства и Android подключаются отдельно; учебные мобильные пакеты не применяются к рабочей базе.
- Обновлены встроенный самоучитель и руководство. В рабочем хозяйстве действие создания из деморежима не показывается.

## Обновление и сохранность

Устанавливайте поверх предыдущего приложения под той же учетной записью ОС. Обновление само по себе не создает новое хозяйство и не очищает данные: стадо, пользователи, настройки, папки данных и системные хранилища ключей сохраняются. Android обновляйте без удаления приложения и очистки его данных; используется постоянный сертификат выпусков.

Переход из демо выполняется только отдельным действием администратора. Архив учебной базы сохраняется в `backups/before-working-farm-….otara-backup`; путь показывается после успешного создания. Это отдельное хозяйство, а не переключатель режимов: его архив не восстанавливается поверх новой рабочей базы. Для восстановления другого хозяйства требуется отдельная чистая база. Копия базы сама по себе не переносит системное хранилище ключей на другой компьютер.

Версия 2.3.3 сохраняет обычный минимальный уровень читателя 2.3.2; новая обязательная миграция формата базы для этого исправления не вводится. Перед любым откатом сохраните текущую резервную копию и проверьте совместимость в разделе «Версии ПО».
