# Отара Local — дистрибутивы

Локальная программа управления овцеводческим хозяйством для **macOS 13+ (Apple Silicon/Intel), Windows x64 и Android 8+**. Русский интерфейс; повседневный учет работает без интернета. Облачный обмен, государственные запросы и онлайн-поддержка требуют сети и настроенных доступов.

## Что нового

«Прогнозирование» сравнивает до 32 заданных сценариев: приплод, привесы, сохранность, товарные цели, ресурсы, кормовой и пастбищный бюджет, ремонт маток и баранов, происхождение и скрещивание, экономика. Неизвестные данные видны явно. Расчет одной кампании с одним будущим окотом не изменяет рабочие планы и не является гарантией результата.

Породные профили Романовской, Катумской и Дорпера автоматически показывают подходящие исследования и замечания в прогнозе, кормлении, профилактике и карточках животных. В библиотеке 29 источников, 33 числовых ориентира и 33 рекомендации. Введенные показатели сохраняются; числовые нормы, рационы и ветеринарные назначения требуют решения специалиста. Ссылки и условия исследований доступны в программе.

В Саппорте отправка администратором из центрального приложения означает разрешение подготовить предложение без повторного согласования. Обращения работников проходят установленную проверку и, кроме узкого случая опечаток в справке, согласование администратора. Перед подготовкой проверяется соответствие клиента, сервиса и опубликованной версии с ее исходной ревизией. Заявки сохраняются до обновления/повторной проверки. Результат — черновой PR с тестами или отчет для ручной разработки; автоматического слияния, выпуска либо установки нет.

Подключения, обращения и резервные копии разделены по хозяйствам и установкам. Общий ключ провайдера не объединяет данные ферм; восстановление другой фермы выполняется отдельно от активной базы.

## Обновление с сохранением данных

Перед обновлением сохраните резервную копию и ключ восстановления. Закройте программу и установите обновление поверх прежней версии под той же учетной записью ОС, сохраняя каталог данных. На macOS замените приложение в «Программах»; на Windows запустите Setup. Стадо, пользователи, история, настройки, токены и ключи остаются в постоянных хранилищах. macOS может повторно запросить доступ к Связке ключей.

На Android установите APK как обновление, без удаления приложения и очистки данных. Сохраняются задания, неотправленные события, облачные доступы и профиль весов. Для онлайн-подключения к локальному сервису после 1.0 получите у администратора новый профиль сопряжения, привязанный к хозяйству, и импортируйте его через «Сопряжение с сервисом поддержки». Это не удаляет задания или очередь обмена.

Перенос на другую машину — отдельная процедура: резервная копия базы не содержит системных секретов. Руководство доступно внутри программы в разделе «Обзор».

## О файлах

Ключи API и данные хозяйств в дистрибутивы не включены. Исходный проект приватный; этот репозиторий содержит публичные установщики. Исходная ревизия 1.1.0: `e92b0692a5caa1d6919848d9c7187d0e27fc7940`; она также указана в манифесте обновления.

Пилотные сборки: Windows без издательской Authenticode-подписи, macOS с ad-hoc подписью без Apple notarization. Android использует постоянный сертификат выпусков начиная с 0.4.0. Контрольные суммы позволяют проверить целостность файлов; они не заменяют подпись издателя или профильную проверку решений по стаду.
