# Отара Local 2.3.4

Локальная программа для овцеводческого хозяйства: macOS 13+, Windows 10 x64 1809+ / Windows 11 x64 и Android 8+. Русский интерфейс, центральная база на компьютере, автономный учёт. После настройки обмена Android получает задания и передаёт факты через GitHub или Яндекс.Диск.

## Изменения 2.3.4

- Импорт приобретённых овец по публичной ссылке ВСД Меркурий и из индивидуальной выгрузки Хорриот. Предпросмотр показывает новые карточки, дополнения, повторы и конфликты; запись выполняется после проверки пользователем.
- Последовательные документы связываются с существующими животными по индивидуальным идентификаторам. Внутрихозяйственный номер поставщика не считается глобальным идентификатором. Неоднозначности требуют решения; сводное количество голов без индивидуальной описи не создаёт карточки.
- Поддерживаются сопоставление столбцов CSV/TSV, Excel XLSX/XLS и XML последней активной записи Хорриот (active=true, last=true, registrationStatus=ACTIVE). Групповая запись с количеством 1 не становится особью, а тип маркировки не определяется по длине номера. Дата фактической приёмки вводится отдельно от даты оформления ВСД. Источники и результаты импорта сохраняются.
- Публичный ВСД читается без реквизитов ВетИС через ограниченный GET. Загрузка не гасит документ, не регистрирует животных в государственных системах, не оформляет бухгалтерскую покупку и не снимает карантин.
- Настольный Саппорт разделён на самостоятельные диалоги: новый чат, список разговоров, переключение и открытие последних сообщений. Старая переписка сохраняется. Android этого выпуска не добавляет отдельный чат Саппорта.
- Обновлены встроенный самоучитель, руководство и история версий.

## Обновление и сохранность

Устанавливайте поверх предыдущего приложения под той же учётной записью ОС. Обновление само по себе не создаёт новое хозяйство и не очищает данные: стадо, пользователи, настройки, папки данных и системные хранилища ключей сохраняются. Android 20304 обновляется поверх 20303 без удаления приложения и очистки данных; используется постоянный сертификат выпусков.

Перед записью новых чатов или импорта Меркурий / Хорриот создаётся аварийная копия `before-v2.3.4`; требование читателя повышается до 2.3.4. При ошибке резервирования запись отменяется. Такую базу нельзя открывать версией 2.3.3. Если новые структуры ещё не записывались, прежнее требование читателя 2.3.2 сохраняется. Восстановление раннего архива — отдельная операция со сверкой последующих событий, а не обычный откат программы. Копия базы не переносит системное хранилище ключей на другой компьютер.

Публичное чтение ВСД не является авторизованным государственным обменом или гашением. Приёмка закрытых форматов СЕЛЭКС, загрузки и проведения в конкретной базе 1С, государственных квитанций и конкретных весов остаётся отдельной. Физическое управление отсутствующими автоворотами выключено до аппаратного испытания.
