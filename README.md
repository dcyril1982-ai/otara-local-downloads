# Отара Local 2.1.0

Локальная программа для овцеводческого хозяйства: **macOS 13+**, **Windows 10 x64 1809+ / Windows 11 x64** и полевой клиент **Android 8+**. Русский интерфейс, база на центральном компьютере, работа без обязательного облака. При настроенном обмене Android передает задания и факты через GitHub или Яндекс.Диск.

## Новые рабочие процессы

- Воспроизводство: сезоны, очереди диагностики и окотов, все исходы ягнят, уточнение потерь, продуктивность маток и объяснимый подбор пар.
- Учет: исторический состав групп, проверка сомнительных измерений, закрытие периода, разбор поздних фактов, квитанции и повтор исправленных событий обмена.
- Кормление: лабораторные анализы и неопределенность, варианты рационов, ежедневный переход, годность запасов, резервирование и заявки на закупку.
- Ветеринария: случаи, пробы и лабораторные заявки, индивидуальные результаты обработки, назначения по подтвержденной массе. Перед лечебной сменой требуется свежий пакет заданий; назначения по массе требуют Android-версии 2.1.
- Производство и планирование: обратная связь бойни, лактации и контрольные удои, качество молока/шерсти, пастбищные ресурсы, исторические основания затрат и многолетние сценарии с дефицитами по датам.

В «Обзоре» доступен **самоучитель из 49 уроков** и отдельная учебная ферма. В «Версии ПО» сохранена история изменений.

## Обновление и сохранность данных

Устанавливайте новую версию поверх прежней, сохраняя существующее хозяйство. Стадо, пользователи, настройки и секреты в системном хранилище сохраняются. На Android обновляйте приложение с той же подписью, без удаления очереди событий.

Перед первой записью данных 2.1 создается локальная копия `before-v2.1-…`. Если сохранить ее не удалось, запись отменяется. После перехода базы на требование читателя 2.1 **старое приложение 2.0 блокирует ее открытие и изменение**. Возврат к 2.0 требует отдельной совместимой копии до обновления; более поздние факты в такую копию не входят. Простой откат установщика не является восстановлением базы.

## Проверки и границы применения

Исходная ревизия: [`9c3c73679c199ef093d3dc919da375392678d687`](https://github.com/dcyril1982-ai/otara-local/commit/9c3c73679c199ef093d3dc919da375392678d687). Пройдены **561 общий автоматический тест**, сборки macOS, Windows и Android и проверки сохранности при обновлении. Android API 35: 287 проверок протокола, 20 подготовки прежней установки и 33 после обновления. Все четыре задания [CI № 43422628090](https://github.com/dcyril1982-ai/otara-local/actions/runs/43422628090) завершились успешно; исходный репозиторий и CI доступны при наличии прав. Проверки используют синтетические данные и отдельные тестовые ключи.

Сборки предназначены для пилотного внедрения. macOS использует ad-hoc подпись без Developer ID/notarization; установщик Otara для Windows пока без издательской подписи. Публичный Android APK подписывается постоянным сертификатом выпуска. Подтверждение запуска выполняется штатными средствами ОС.

Поддержаны открытые таблицы CSV/TSV СЕЛЭКС; нативные закрытые форматы ПЛИНОР требуют контрольных файлов. Прием документов и недублирование в конкретной 1С БП 3.0, полномочия государственных шлюзов и работа конкретных весов/молокомеров требуют отдельной приемки. Физическое управление автоворотами не включено: подготовительная тестовая сессия сохраняет HOLD.

Расчеты используют явно заданные допущения и версии справочников. Рационы и ветеринарные назначения утверждают ответственные специалисты; программные тесты не подтверждают их биологическую применимость. Синтетическая нагрузка и учебные сценарии не заменяют испытание на оборудовании и с персоналом конкретной фермы.
