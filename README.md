# Отара Local 2.2.0

Локальная программа для овцеводческого хозяйства: **macOS 13+**, **Windows 10 x64 1809+ / Windows 11 x64** и полевой клиент **Android 8+**. Русский интерфейс, центральная база на компьютере, работа без обязательного облака. При настройке обмена Android получает задания и передаёт факты через GitHub или Яндекс.Диск.

## Изменения 2.2

- P0: единая очередь качества происхождения, идентификаторов и переписи; атомарный отказ при дублях внутри миграционного файла.
- Полная история особи с фильтрами; резервы и свободный остаток кормов, QR и прослеживаемость партий; личный Обзор по роли и сезону.
- Пересчитанные кормовые альтернативы с защитой потребностей других групп; микроэлементы, единицы и область применимости справочных норм.
- Полный контекст ветеринарных ограничений; учёт количества, хранения, расхода и утилизации материала проб. Поздний результат не снимает запрет задним числом.
- Проверка пастбища при фактическом входе; ограничения продажи молока на даты надоев; точное распределение затрат и защита от повторного расхода связанных фактов.
- Структурированные справочники и **49 уроков самоучителя**, включая отдельную учебную ферму.
- Android: устранены лишние полные копии пакета при сохранении; исправлен облачный вход ветеринара и зоотехника. Добавлены проверки отказа записи, восстановления очереди и разрешённых мобильных ролей.

## Обновление и сохранность

Устанавливайте поверх прежнего приложения под той же учётной записью ОС. Сохраняются папка базы, стадо, пользователи, настройки и системные хранилища ключей. Android обновляйте без удаления приложения и очистки данных; APK использует постоянный сертификат выпусков.

Перед первой записью с требованием версии 2.2 создаётся копия `before-v2.2-…`. Ошибка её создания отменяет запись. База после перехода требует 2.2: приложение 2.1 блокирует её открытие и изменение. Возврат к старой версии требует отдельной совместимой копии до обновления; последующие факты в такую копию не входят. Копия базы сама по себе не переносит системное хранилище секретов на другой компьютер.

## Проверки и границы применения

Исходная ревизия: [`22b741a45261d9b377ba5e553f399435aec885be`](https://github.com/dcyril1982-ai/otara-local/commit/22b741a45261d9b377ba5e553f399435aec885be). Все четыре задания [CI № 43445835604](https://github.com/dcyril1982-ai/otara-local/actions/runs/43445835604) завершились успешно: общие тесты, macOS, Windows и Android. Исходный репозиторий и CI доступны при наличии прав. Проверки используют синтетические хозяйства и отдельные тестовые ключи.

Проверены 609 общих автоматических тестов, пользовательские формы и отчёты, переход с предыдущей версии, SQLite/WAL и сохранение секретов в изолированных тестах. Нагрузочный профиль центральной базы: **10 000 животных, пять лет, 600 000 взвешиваний**. Мобильный пакет: **10 000 животных и 60 000 годовых измерений**; десять идентификаторов устройств проверяются последовательно. Это не испытание десяти физических телефонов одновременно. Скорость зависит от оборудования, истории и фотографий.

Сборки для пилотного внедрения: macOS с ad-hoc подписью, без Developer ID/notarization; установщик Otara для Windows без издательской Authenticode-подписи. Публичный APK подписан постоянным сертификатом. Установщики не запускаются автоматически.

Открытые CSV/TSV-профили СЕЛЭКС поддержаны; закрытые нативные форматы ПЛИНОР требуют контрольных файлов. Приём и недублирование документов в конкретной **1С БП 3.0**, полномочия и подтверждения государственных шлюзов, реальные весы/считыватели/молокомеры требуют внешней приёмки. ФГИАС ПР использует подготовку пакета для ручного портала. Автоворот на ферме нет: подготовлен модуль подключения, физическое управление выключено.

Расчёты имеют явные источники и допущения. Кормовые и ветеринарные решения утверждают ответственные специалисты; программные тесты не доказывают биологическую применимость. Непроведённые внешние проверки не объявляются выполненными.
